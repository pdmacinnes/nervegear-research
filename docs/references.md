# Reading list and source index

Evidence baseline: October 14, 2026. Start with the readout, tactile feedback, and proprioception papers. Then read the interface and safety work that constrains a complete system.

This is a source index for the initial review. It is not an exhaustive bibliography or a record of independent replication. Some material is accessible through abstracts, figures, author versions, or institutional summaries. Verify the methods and supplements before using a result to design an experiment. Linked publications, datasets, and code retain their own licenses.

Use the cited papers to track actual results. Affiliations and company relationships change. Sliman Bensmaia's work remains foundational to tactile neuroscience and cortical sensory interfaces.
