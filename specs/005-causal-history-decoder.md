# Spec: Causal EMG history versus a single RMS window

## Requirements & Goals

Status: Explicitly approved by the maintainer through the spec-review prompt on October 15, 2026 with "Approve and continue". Implement and run this study against the fixed protocol.

Test whether several recent EMG feature vectors improve held-out pose prediction over the existing single-window decoder. The [temporal alignment audit](../docs/experiments/temporal-alignment-v1.md) found lower aggregate error for aligned predictions than for fixed shifts. That result motivates a bounded history comparison, while the competitive constant-pose controls remain essential.

Use only original custom-pilot training recordings 1-9, holding out each once. These recordings and previous outcomes have already been inspected. This is exploratory analysis of one person and session, not a blind test, an official emg2pose benchmark, or a preregistration. Original custom validation and test files remain excluded from verification, loading, fitting, and scoring.

Compare fixed causal representations without model or hyperparameter selection. Use ordinary ridge regression and existing dependencies. Do not add a recurrent network, output smoothing, velocity target, target-time shift, intercept calibration, autoregressive pose input, or teacher forcing. No future input or later label may enter a prediction. Preserve all prior protocols and results.

The complete study requires no hardware, new recording, participant, download, GPU, paid service, or new Python dependency. Use the existing CPU environment with two numerical-library threads and a 15-minute command limit. A negative or unsupported result is a complete research outcome.

## Inputs, Outputs & Behavior

Inputs are the existing source manifest, nine training HDF5 files, and a new `research/emg2pose/history-v1.json` numeric protocol. Commit the protocol after approval and before real-data fitting or coverage inspection. Add `python -m nervegear_benchmark history --data-dir <directory> --output <new-directory>`. Support an explicitly validated `--history-protocol` copy and reject that option for other commands. Preserve current commands and options.

Produce a fresh directory with the numeric protocol and canonical fingerprint, verified nine-file inventory, coverage and support counts, aggregate errors, integrity digests, a Markdown report, SVG plots, resource measurements, and a completion marker. Publish no raw signals, per-sample labels or predictions, or fitted coefficients.

The normal flow is:

1. Validate source metadata and select only custom training entries before checking files. Verify checksums and schemas. Require finite, strictly increasing timestamps. Reuse the current input validity rule, including finite EMG and timestamp steps between 0.00025 and 0.00075 seconds, inclusive. Reuse the current target-reference validity rule.
2. Retain the original grid phase: endpoints are `1199 + 40*k` for nonnegative integer `k`, continuing while the endpoint is inside the recording. This removes the first 20 original grid rows to allow 1,200 samples of history without negative indices or padding. No window crosses a file boundary.
3. At each endpoint `e`, construct three representations from raw EMG. The current representation has 16 log1p RMS features over samples `e-399` through `e`, inclusive. The wide representation has 16 log1p RMS features over `e-1199` through `e`. The history representation concatenates five 16-feature vectors, newest first, using 400-sample windows ending at `e`, `e-200`, `e-400`, `e-600`, and `e-800`. These are nominal ages 0, 100, 200, 300, and 400 ms. The complete union spans 1,200 samples, nominally 600 ms. Compute the wide RMS directly from raw samples, not by averaging log features. No interpolation, future samples, or padding is allowed.
4. Require valid EMG and timestamp steps throughout the complete 1,200-sample span for every method. Only the current target reference determines label validity. Historic reference labels are unnecessary and must not exclude a history window. Report grid, input-valid, and reference-valid output counts before partitioning.
5. In each fold, fit every model using the identical eligible outputs from the other eight recordings. Fit feature means and standard deviations on those outputs only, separately for each representation. Constant columns retain unit scale. Fit the training-median pose on the same labels. No part of the held-out recording enters fitting or standardization. Empty eligible fitting data fail even if the target fold would be unsupported. Chronology does not restrict the other eight recordings, so this remains offline cross-validation.
6. Fix ridge alpha at 10 for the two 16-feature representations, with an unpenalized intercept. For the 80-feature history representation, divide the training-standardized features by `sqrt(5)` before fitting ridge alpha 10 and apply the same division during prediction. An equivalent implementation can fit the unscaled standardized stack with alpha 50. Prove that a stack made of five identical copies of the current features produces the same predictions as current-feature ridge alpha 10, within numerical tolerance. This prevents feature duplication alone from weakening regularization. The history model still has more parameters, so the comparison does not isolate temporal order from model capacity.
7. Define elapsed time from the held-out recording's first timestamp. The prefix includes common eligible outputs strictly before 10.0 seconds. Compute a prefix-median pose using only those labels, with a minimum of 25 valid prefix outputs. The prefix provides no fitted decoder parameters. These labels come from public reference angles and do not provide a hardware-free live calibration method.
8. Score common eligible outputs with endpoint elapsed time at least 10.6 seconds and complete 1,200-sample history beginning at or after 10.0 seconds. This fixes a 600 ms embargo and prevents any scored feature history from overlapping the prefix. Require at least 100 scored outputs. Insufficient prefix labels or scoring support makes the fold unsupported for all methods together. Never extend the prefix, change warm-up or embargo boundaries, or relax validity after seeing results. Report successive prefix, embargo, and scoring counts, including invalid-input and invalid-reference exclusions.
9. Evaluate five methods on identical scored timestamps: current-window ridge, wide-window ridge, history ridge, training-median pose, and prefix-median pose. Use raw predictions without clipping, output filtering, or adaptive offsets. Report per-fold and per-joint angular MAE, MSE, and RMSE in radians, with degrees for display. Macro MAE weights supported folds equally. Report sample-weighted MAE separately. Macro RMSE is the square root of mean fold MSE.
10. The primary comparison is history-ridge MAE minus current-window-ridge MAE. Secondary comparisons are history ridge minus wide-window ridge and history ridge minus prefix median. Report all five methods, every fold, paired differences, and improved, tied, and worsened fold counts with a fixed 1e-12-radian tie tolerance. Negative means lower history-ridge error. Do not select a model, change a metric, or declare a population-level improvement from these outcomes.
11. Write per-model fit digests, a prefix-control digest, a common scored-mask digest, and per-method prediction digests. Record the effective alpha and representation dimension for each model. Measure internal wall time, CPU time, peak process memory, and full-process wall time separately. Refuse existing output directories. Write a completion marker only after all outputs succeed. An entirely unsupported study has null aggregate errors and visible reasons, not fabricated zeros.

The longer common history changes fitting eligibility, warm-up, prefix labels, and scored targets relative to earlier studies. Refit and rescore every comparator here. Differences against previously published numbers do not measure the effect of history alone. Folds overlap in fitting data, and nearby timestamps are correlated. Report descriptive results without population confidence intervals or significance tests.

An improvement would support this fixed history representation on these recordings. It would not establish an optimal duration, temporal-order mechanism, physiological latency, new-person performance, stationary intention decoding, live control, or full-dive capability. If history fails, do not infer that all temporal models fail or launch a replacement study automatically.

## Edge Cases & Error Handling

- Missing or unusable original validation and test files cannot affect scientific results. Missing, corrupt, or incompatible required training files fail with useful filenames and no successful completion marker.
- Empty or invalid timestamps fail rather than being reordered. An internal gap invalidates the full input span. Nonfinite input follows the common mask without filling. Historic label gaps alone do not invalidate a target.
- A recording shorter than 1,200 samples has an empty grid and an explicit unsupported reason if fitting data remain available elsewhere. Empty fitting data always fail. Exactly 25 prefix labels and exactly 100 scored outputs meet their respective minimums.
- No eligible prefix or scored outputs produces unsupported status with counts, not an attempted empty median or zero error. Every method uses the same supported-fold set. An all-unsupported study still reports reasons and null aggregates.
- Reject unsupported or unexpected protocol fields and command-specific option misuse. Canonical JSON fingerprints ignore whitespace and line endings, while recording hashes identify exact bytes.
- Nonfinite fitted parameters, predictions, or required metrics fail explicitly. Null values are reserved for unsupported results. A failed or timed-out run cannot publish a successful completion marker. Do not acquire more data or compute as a fallback.
